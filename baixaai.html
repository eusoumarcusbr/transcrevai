Instalar o BaixaAI

O BaixaAI é um complemento do Chrome que pega o áudio de links do YouTube, Instagram, TikTok, Facebook e Globo e entrega para o TranscrevAI. Tudo acontece no seu computador: nenhum vídeo é enviado para servidor nenhum.

Esta instalação é feita no computador. O BaixaAI não existe para celular, mas o TranscrevAI funciona normalmente aqui pela aba Arquivo.
Verificando se o BaixaAI já está instalado…

Baixe e descompacte

São uns 30 KB. Depois de descompactar, guarde a pasta baixaai num lugar definitivo, como Documentos. Se você apagar ou mover essa pasta depois, o complemento para de funcionar.

Baixar o BaixaAI (.zip) Funciona no Chrome e no Edge, no Mac e no Windows.

Coloque a extensão no Chrome

  1. Abra uma aba nova e vá em chrome://extensions
  2. Ligue o Modo desenvolvedor, no canto superior direito
  3. Clique em Carregar sem compactação
  4. Selecione a pasta baixaai que você descompactou

O ícone do BaixaAI vai aparecer na barra do Chrome. No Edge o caminho é edge://extensions e o botão se chama "Carregar descompactado".

Instale o ajudante do computador

Essa parte é o que realmente baixa o áudio. Sem ela a extensão aparece instalada, mas os links não funcionam.

Abra o Terminal e cole as duas linhas abaixo, uma de cada vez. Troque o caminho pelo lugar onde você guardou a pasta.

cd ~/Documents/baixaai/native-host
bash install.sh

Dica: em vez de digitar o caminho, escreva cd, dê um espaço e arraste a pasta native-host para dentro do Terminal. O script demora um pouco: ele instala o yt-dlp e o ffmpeg e registra o ajudante no Chrome. Precisa de Python 3, que o Mac já traz.

Antes: instale o Python 3 pelo site python.org e marque a caixa "Add python.exe to PATH" durante a instalação.

Depois abra a pasta native-host no Explorador de Arquivos, clique com o botão direito num espaço vazio e escolha Abrir no Terminal (ou "Abrir janela do PowerShell aqui"). Cole:

powershell -ExecutionPolicy Bypass -File install.ps1

O script instala o yt-dlp, o ffmpeg e registra o ajudante no Chrome. O suporte a Windows é recente e foi menos testado que o do Mac.

Volte aqui e recarregue

Feche e abra o Chrome, volte para o TranscrevAI e recarregue a página. No topo deve aparecer BaixaAI conectado. A partir daí é só colar o link na aba Link.

Se der problema

Diz "BaixaAI: atualize o ajudante"

A extensão está lá, mas o ajudante do computador não respondeu. Rode o instalador de novo (passo 3) e recarregue a página.

A pasta está num HD ou SSD externo (Mac)

O macOS costuma bloquear o Chrome de executar programas em volumes externos, e aparece "Native host has exited". Mova pelo menos a pasta native-host para dentro da sua pasta pessoal e rode o install.sh de lá.

O Chrome desativou a extensão

Extensão carregada sem compactação às vezes é desativada quando o Chrome atualiza. Volte em chrome://extensions e ligue de novo. Se a pasta tiver sido movida ou apagada, carregue outra vez.

Nada acontece ao colar o link

O download roda fora do Chrome e não avisa nada enquanto trabalha. Arquivos grandes demoram. Se travar de verdade, o registro do que aconteceu fica em Downloads/BaixaAI/.logs/.

Uso Safari ou Firefox

O BaixaAI só existe para Chrome e Edge. Nesses outros navegadores o TranscrevAI continua funcionando normal pela aba Arquivo: baixe o vídeo e envie o arquivo.

O BaixaAI e o TranscrevAI rodam no seu computador. Nada é enviado para servidores.
